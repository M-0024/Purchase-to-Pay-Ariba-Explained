# Purchase-to-Pay-Ariba-Explained
# P2P Process — Interview Prep

A working repo of Purchase-to-Pay (P2P) process notes, built to prepare for P2P-focused interviews (e.g., PepsiCo) and to reinforce retention of upstream procurement concepts alongside my existing AP/downstream experience.

## Why this repo exists

My day-to-day work sits on the **downstream** side of P2P — invoice processing, 3-way match holds, vendor helpdesk queries (Germany AP, Baker Hughes account, SAP HANA). Interviews for broader P2P roles test the **upstream** side just as hard: PR creation, sourcing, vendor selection, and PO mechanics in tools like SAP Ariba. Writing this out in my own words is how I retain it — same approach as my BA notes and FP&A repos.

## Structure

| File | Contents |
|---|---|
| `01-p2p-cycle-overview.md` | End-to-end P2P map — upstream vs downstream, where each step hands off to the next |
| `02-pr-deep-dive.md` | Purchase Requisition: triggers, required fields/criteria, approval workflow, correction process, PR vs PO distinction |
| `03-sourcing-and-vendor-selection.md` | When sourcing is triggered, RFI/RFQ/RFP flow, vendor evaluation criteria (goods vs services), vendor onboarding |
| `04-po-deep-dive.md` | PO types (standard, blanket, contract-referenced), issuance, change/amendment process |
| `05-ariba-notes.md` | SAP Ariba specifics — Buying, Sourcing, Contracts, Network modules and how PR/PO flow through each |
| `06-interview-qna.md` | Question-to-answer pairs in my own words, rehearsed for spoken delivery |
| `07-tying-it-to-ap.md` | How my actual AP/downstream experience (GRN, 3-way match, holds) connects back to upstream steps — my bridge story for interviews |

## How I use this

Each concept file follows the same shape: **definition → process steps in order → one applied example** (real or plausible synthetic, drawn from FMCG/Germany AP context) — so answers sound like applied understanding, not textbook recall.
